# Tradeview

Нативный macOS MVP для обзора рынка, скрининга акций и прозрачных инвестиционных
сигналов. Приложение написано на **SwiftUI**, использует **Swift Charts** и
запускается как обычный Xcode-проект (`Tradeview.xcodeproj`) и также содержит
Swift Package для независимой проверки Core-слоя.

## Возможности MVP

- Обзор рынка с индексами, выбранными сигналами и графиком динамики.
- Скринер по названию/тикеру, сектору, действию, уверенности и сортировке.
- Карточка акции с действием, горизонтом, уверенностью, сценариями, драйверами,
  рисками и объяснением сигнала.
- Вероятность отображается **только** для явно сформулированного события.
- Локально сохраняемые watchlist и введённый вручную портфель.
- Демо-портфель и анализ концентрации по позиции и сектору.
- История сигналов с датой формирования, обоснованием и источником данных.
- Постоянно видимое предупреждение: это не гарантия и не персональная
  инвестиционная рекомендация.

## Данные и безопасность

По умолчанию используется детерминированный офлайн-демо-набор. В интерфейсе
показываются источник, время снимка и версия модели.

`MarketDataProviding` определяет безопасную границу источника данных.
`BackendAPIClient` принимает только HTTPS endpoint и получает нормализованный
`MarketSnapshot`; ключи поставщиков данных, брокерские ключи и брокерская
авторизация в приложение не встроены и не реализованы. В production ключи
должны находиться исключительно на backend.

## Запуск и проверка

Требования: macOS 14+, Xcode 15.3+ или Swift 5.10+.

```bash
open Tradeview.xcodeproj
xcodebuild -project Tradeview.xcodeproj -scheme Tradeview -configuration Debug build
xcodebuild -project Tradeview.xcodeproj -scheme Tradeview -configuration Debug test
```

Для проверки модели и источников данных без UI можно использовать:

```bash
swift build --target TradeviewCore
swift test --filter TradeviewCoreTests
```

Это демонстрационный аналитический инструмент. Рыночные значения в офлайн-режиме
не являются котировками реального времени и не должны использоваться для
исполнения сделок.
